# Timestamp fonts

These open-license static fonts are served with the application and shared by canvas preview and FFmpeg export. No external font CDN is used at runtime.

- Roboto Regular/Bold: https://github.com/googlefonts/roboto-2/tree/main/src/hinted — Apache 2.0; see Roboto-LICENSE.txt.
- Roboto Mono Regular/Bold: https://github.com/googlefonts/RobotoMono/tree/main/fonts/ttf — SIL Open Font License; see RobotoMono-OFL.txt.
- Noto Serif Regular/Bold: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSerif — SIL Open Font License; see NotoSerif-LICENSE.txt.

Downloaded 2026-10-03. Original filenames and font binaries are preserved.

Italic/BoldItalic faces are static instances of the Google Fonts `ofl/roboto`, `ofl/robotomono`, and `ofl/notoserif` italic variable fonts, downloaded on 2026-10-03 and instantiated at weights 400/700 with default width. Each italic family includes its OFL license.
